## 项目简介

PidanUI 是一个由 EggyUI 前开发者 Pidan-Eggy 与其芙米皮蛋团队开发的 Windows 桌面美化项目，专注于实现《蛋仔派对》风格的 Windows 桌面美化。它不是 EggyUI 的衍生分支，而是 EggyUI 走向分裂后的产物，是一个全新的项目。

## 为什么要创建 PidanUI

### 根本原因

EggyUI 项目组的斗争与内耗贯穿其整个生命周期——之前是这样，现在还是这样。项目早期便深陷治理危机，核心成员间沟通不畅、决策不透明，关键权限高度集中且缺乏制衡。这种内耗在 EggyUI 走向末期时愈演愈烈，甚至在项目分裂后仍未停止。

与此同时，部分成员推动着与项目性质严重不符的议程。成员"春之长长之城"（原名：游戏解说员ovo）试图推动项目组公司化运作——进入项目组需要面试，且要签署保密协议。然而 EggyUI 本身是一个爱好者发起的非盈利项目，不存在什么商业机密，根本没有必要设置保密协议。此外，成员"何以青春"（别名：小柒订婚快乐，原名：20年冬）试图推动项目与网易合作，这一不切实际的幻想进一步消耗了团队的精力与凝聚力。

## 项目特色

作为 EggyUI 走向分裂后的产物，PidanUI 继承了此前在部分 EggyUI 分支项目中由冷落的小情绪主导推进的核心特性：

- **辅助组件技术栈使用 .NET 10**：抛弃了早期 EggyUI 大量使用的易语言，采用现代化的 .NET 10 框架进行开发，解决了易语言程序在高DPI缩放下的适配问题以及杀毒软件误报问题，提升了组件的稳定性和用户体验。
- **不修改系统文件**：所有美化内容均通过主题包、壁纸、音效等安全方式部署，不替换 `imageres.dll.mun`、`shell32.dll.mun` 等系统核心文件，用户无需担心系统异常或无法启动的问题，卸载时只需切换回默认主题即可恢复。
- **精简版美化**：移除了冗余、持久化的美化特性，仅保留基础美化（如定制主题、Rainmeter 小组件等），让系统体验更接近原版 Windows，适合作为主力系统使用。

## 结语

PidanUI 诞生于 EggyUI 项目的分裂之中，它承载了前开发者对蛋仔美学桌面美化的持续探索。在告别了无休止的内耗与不切实际的幻想之后，PidanUI 选择了一条更务实、更安全的道路——以精简的美化特性、现代化的技术栈和不修改系统文件的设计理念，为用户提供稳定、安心的桌面美化体验。故事曾在混乱中告一段落，但代码与热情将在新的项目中延续。
